Fila diária

Um grupo pode enviar vários arquivos no mesmo dia e cada arquivo pode conter um ou vários pagamentos. Primeiro identificamos os pagamentos de cada arquivo; depois conciliamos cada pagamento com o extrato.

Revisão automática

O sistema sugere o melhor lançamento bancário para cada pagamento. Match forte exige valor exato, mesma data e compatibilidade de beneficiário. Possíveis e conflitos ficam para revisão manual.

Adicionar espelhos do WhatsApp

Você pode adicionar novos arquivos a qualquer momento. Os já carregados são preservados e duplicados exatos são ignorados. Uma imagem pode conter vários pagamentos.

Limpar arquivos do trabalho

Escolha exatamente o que deseja apagar. Esta ação não afeta os arquivos originais no seu computador.

Espelhos / WhatsApp
